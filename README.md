# 看视频学俄语 🎬

把视频拆成一句句台词，按 **听 → 听写 → 跟读** 逐句练俄语；点任意单词查译；生词自动进间隔重复复习；长难句有「AI 老师」逐词讲解。

## 快速开始

```bash
# 1. 装依赖
#    yt-dlp          抓 YouTube 字幕
#    razdel          俄语无标点字幕断句
#    faster-whisper  「从音频识别字幕」语音转写（可选：本地视频无字幕时用，纯本地无需 key）
pip install yt-dlp razdel faster-whisper

# 2. 启动
python server.py
```

然后浏览器打开 **http://localhost:8000**

> 为什么不能直接双击 `index.html`？浏览器语音识别（跟读）和自动抓字幕都需要 `localhost` 环境，`file://` 下用不了。

## 怎么用

1. **导入材料**：点右上「＋ 导入材料」
   - 视频：贴 YouTube 链接，或上传本地视频文件
   - 字幕：点「⚡ 自动抓字幕」自动下载俄语字幕（含自动生成字幕），或手动粘贴 SRT/VTT/纯文本
   - 没有字幕？点顶栏「🎙 音频识别」，粘贴视频链接 → 自动下载音频并识别成一句句带时间戳的俄语台词（本地 Whisper，无需 key）
   - 也可以点「用示例数据试试」先体验
2. **学习**：逐句走三个关卡——`听`（隐藏原文听）、`听写`（打字比对，红字标错）、`跟读`（麦克风识别比对 / 自评）
3. **点词翻译**：点击台词里的任意俄语单词 → 弹释义 →「＋ 加入生词」
4. **生词本**：右上角打开，到期的词会按记忆曲线（SM-2 间隔重复）复习
5. **AI 解析**：句子上点「🤖 AI 解析」→ 先到「设置」填你自己的 LLM Key（DeepSeek 等 OpenAI 兼容接口）

## 数据存在哪

全部存本机浏览器：学习材料、生词、设置、翻译缓存。点「设置 → 导出备份」可导出 JSON，换设备可「导入备份」。

> 本地视频文件存浏览器 IndexedDB；YouTube 链接只存链接，不存视频文件。

## 常见问题

- **抓字幕失败**：该视频可能没有俄语字幕，或没装 `yt-dlp`（`pip install yt-dlp`）。
- **AI 解析报错**：设置里的 baseUrl / Key / 模型名没填对，或网络不通。
- **语音识别不可用**：用 Chrome / Edge 打开 `localhost` 地址；Safari/Firefox 可能不支持，用「自评」按钮代替。

## 文件

- `index.html` —— 整个 App（单文件前端，无构建）
- `server.py` —— 本地启动脚本（静态页 + 抓字幕 + 转发翻译/AI 请求）
